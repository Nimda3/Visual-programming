# Модель движения: Random Walk 

## Принцип работы

Random Walk - это простейшая модель случайного движения, где объект на каждом шаге движется в случайном направлении.

## Формулы

1. **Генерация случайного угла:**
   θ = random(0, 2π)
   где θ - угол направления в радианах

2. **Расчет нового положения:**
   x_{n+1} = x_n + v × cos(θ)
   y_{n+1} = y_n + v × sin(θ)
   где:
- `x_n`, `y_n` - текущие координаты
- `v` - скорость движения
- `θ` - случайный угол направления

## Особенности модели
- Движение полностью случайное
- Не зависит от предыдущего направления
- Простая в реализации
- Подходит для моделирования хаотичного движения
